## 兽医止血生理学互动模拟器 - 项目开发计划书

### 一、 项目概述

**项目定位：** 一款面向动物医院临床兽医与见习助理的互动式 Web 学习应用。
**核心教学目标：** 演示基于**细胞基础模型 (Cell-based Model)** 的现代止血生理学过程，并直观对比常见临床凝血障碍的病理机制。
**技术栈：** HTML5, CSS3 (伪 3D 渲染), JavaScript (Vanilla JS), GSAP (绿袜动画库)。
**交互模式：** 融合“幻灯片式流程引导”与“自由探索式受体/因子信息查阅”。

---

### 二、 核心内容与机制映射表

| 阶段 / 状态 | 正常生理表现 (Normal) | 对应病理状态与演示效果 (Pathological) |
| --- | --- | --- |
| **0. 血管损伤** | 内皮受损，暴露底层胶原与组织因子。 | (无特殊异常对比) |
| **1. 初级止血** | vWF 桥接胶原与血小板 (GP Ib-IX-V)，血小板粘附聚集。 | **血管性血友病 (vWD)：** vWF 缺失，血小板无法粘附，被血流冲走。 |
| **2. 起始阶段** | 组织因子 (TF) 结合 FVIIa，微量活化 FX/FIX，产出微量凝血酶。 | **维生素K拮抗剂中毒：** FVII, FIX, FX, FII 未羧化呈灰色，无法结合细胞膜。 |
| **3. 放大阶段** | 微量凝血酶活化血小板 (PAR受体)，并活化辅因子 FV, FVIII 及 FXI。 | (无特殊异常对比) |
| **4. 传播阶段** | 组装 Tenase 与 Prothrombinase 复合物，凝血酶大爆发，形成纤维蛋白网。 | **血友病A：** FVIII 缺失，Tenase 无法组装，凝血酶爆发失败。 |

### 三、 目前已完成开发阶段 (Phase 1)

* **框架搭建：** 完成了基础的 HTML 骨架，划分为侧边栏控制区、中央伪3D舞台区和底部时间轴。
* **视觉原型：** 利用 CSS 的径向渐变、阴影和 `perspective` 属性，构建了具备纵深感的血管腔视角，并设计了不同凝血因子的区分样式。
* **状态机逻辑：** 使用 JavaScript 实现了 `currentCondition` (病理状态) 和 `currentStage` (生理阶段) 的全局状态管理。
* **核心动画引擎：** 引入 GSAP，编写了初级止血、起始、放大和传播阶段的 DOM 元素位移与形变动画。
* **病理拦截机制：** 实现了在特定阶段根据临床状态（如 vWD、Vit K 中毒）中断动画，并弹出解释警告框的功能。

### 四、 未来开发待处理事项 (Phase 2 & 3)

以下是为您整理的后续开发 To-Do List。结合您上传的兽医临床疾病百科 (VINcyclopedia) 资料，我特别加入了高阶病理状态的扩展计划。

**1. 视觉资产升级 (UI/UX)**

* **绘制矢量图形 (SVG)：** 替换目前 CSS 绘制的简单圆球，使用带高光和阴影的 SVG 图标（如哑铃状纤维蛋白原、带伪足的活化血小板、跨膜的 TF 受体）。
* **添加信息悬浮窗 (Tooltip)：** 使用 JavaScript 监听鼠标 `mouseenter` 事件。当用户光标悬停在凝血因子上时，显示其全称、半衰期（如 FVII 半衰期极短，对解读 PT 极具临床意义）及正常参考值。
* **优化流体视觉：** 在背景添加 CSS 或 Canvas 驱动的微小红细胞/血浆流动粒子，增强血管内的沉浸感。

**2. 核心代码优化**

* **模块化重构：** 随着动画逻辑变复杂，将 `app.js` 拆分为 `state.js` (状态管理)、`animations.js` (GSAP逻辑) 和 `ui.js` (DOM操作)。
* **响应式布局：** 调整 CSS Flexbox 和 Media Queries，确保应用在平板电脑（兽医诊间常用设备）上完美横屏展示。

**3. 临床病理模块扩展 (重点扩展区)**

* **引入 DIC (弥散性血管内凝血) 模拟：** 根据您上传的文献，设计 DIC 的表现：画面同时出现多处微血栓，凝血因子迅速变暗消失（消耗性低凝状态），并生成代表 D-dimer 的碎片元素。
* **引入 急性创伤性凝血病 (ATC) 模拟：** 表现组织严重损伤下的纤溶亢进，演示纤溶酶原被 tPA 激活，迅速溶解刚刚形成的纤维蛋白网。

**4. 交互式测验功能 (可选)**

* **临床决策小测验：** 在动画结束后，弹出真实化验单（如 PT 延长、aPTT 正常），要求用户根据动画学到的机制，选择最可能的病因（如早期杀鼠剂中毒），形成教学闭环。

**5. 部署与发布**

* **测试兼容性：** 确保在 Chrome, Safari, Edge 上 GSAP 动画运行流畅。
* **静态托管：** 将代码推送到 GitHub，并使用 GitHub Pages 或 Vercel 进行免费的静态网页部署，生成链接供兽医团队使用。
